# 氧化还原知识连接地图——交互原型

> `PROTOTYPE / THROWAWAY`：用于选择信息结构，不是生产系统；不保存姓名或服务器端学生档案，闯关记录仅保存在当前浏览器。

## 打开方式

通过 GitHub Pages 网址可直接试用；下载仓库后双击 `index.html` 也可离线使用，不需要安装依赖或启动服务器。

## 建议测试路径

1. 先打开“真题库”，任选一道题，在不看解析时口述第一步和一句依据。
2. 再看“解题路径”，检查自己停住的是哪个连接，而不是只对答案。
3. 在“断连诊断”中只选择一条有作答证据支持的候选分叉。
4. 回答最小区分问题，执行一次最小修补；达到停止条件即停，不连续刷同类整题。
5. 用未见微变式观察能否重新调用连接。一次成功只记录为一次迁移支持，不写成永久掌握。
6. 进入 `challenge.html`，用选择、判断和填空复习 39 个广义节点；故意答错一次，检查是否只弹出当前节点的最小纠错卡。

三种方案可通过页面底部切换，也可直接使用：

- `index.html?variant=A`：全景关系网——优先看“所有节点怎样连接”。
- `index.html?variant=B`：学习路线地铁图——优先看“应该按什么依赖顺序学习”。
- `index.html?variant=C`：诊断矩阵——优先看“某个断连点怎样被题目、探针和证据观察”。

键盘左右方向键可以切换方案；输入框聚焦时不会拦截按键。

## 已实现的交互

- 点击知识节点查看广义必备陈述、常见高考表面、易混边界和所有相邻连接。
- 在全景关系网中，将鼠标放在知识图上，按 `Ctrl + 鼠标滚轮` 可围绕指针位置缩放；按住空白处拖动可平移画布，点击百分比可重置缩放和位置。
- 选中真题后，节点详情显示“本题调用步骤—本题中发生的变化—不能直接推出”；下方保留不随题目变化的广义必备陈述和高考表面。
- 点击节点下方任一“经过此节点的真题”，整张知识图和节点语境同步切换到该题；旁侧“看原题”保留独立入口。
- 点击连线查看关系类型、适用条件和成立理由。
- 打开“真题库”查看 Q001—Q065 的年份、省份、题号、原题、材料答案与教研解析。
- 可按省份、年份、题号、题型或路径主题搜索 65 个 ItemUnit。
- 按 Q001—Q065 高亮一道真题实际调用的逐步路径；点击路径节点可返回全景图定位。
- 从任一知识节点或连线反查哪些已核验真题调用了它。
- 对每道题查看候选错误分叉、一个最小区分问题、一个最小修补动作、停止条件和未见迁移题。
- 湖南、安徽、江苏、湖北、广东、重庆的装置/机理/表格题保留经过视觉核对的源 PDF 裁图；纯文字子问采用逐字转写。
- 按知识层筛选或搜索节点、关系、例子。
- 在详情面板中循环标记证据状态；状态只保存在当前页面内存中。
- 随时查看完整原型状态，防止界面行为隐藏判断依据。
- 从主界面进入“节点闯关”，用填空、判断、选择三种方式循环调用 39 个节点的广义陈述。
- 答错时只弹出当前节点卡片，展示广义陈述、常见高考表面、错误陈述和一个最小修补动作。
- 闯关归档记录每个节点的正确次数、错误次数、连续正确、最近练习及“未练习/待巩固/暂时掌握”。连续 2 次无提示正确才标记为暂时掌握，之后答错会退回待巩固。

## 证据状态说明

```text
尚未观察
→ 无提示支持一次
→ 提示后可以
→ 候选断连
→ 异表面迁移支持
→ 延迟调用支持
```

这些状态是原型交互语言，不等于“永久掌握”。当前没有导入真实学生证据。

## 公开演示范围

公开仓库只包含运行网页所需的题目摘录、必要题图和教研路径，不包含本地整卷 PDF、学生姓名或服务器端完整画像。地图中的证据标记只存在页面内存，刷新后清空；节点闯关的次数与临时状态保存在当前浏览器 `localStorage`，不会上传。

题卡由本地教研资产整理而来；源 PDF 因体积、公开范围和授权边界不随演示站发布。本演示用于小范围教学设计测试，引用题面与裁图在进一步公开传播前仍应逐项核验使用边界。

原型把这些教师端资产压缩为 39 个学生可导航节点和 48 条带条件连接。它覆盖核心模型、定量、电化学、流程、歧化/归中、有机氧化还原及必要边界；不声称已经收录所有元素化学事实或全部低频题面。

当前真题库接入 65 个已经完成题面、答案、关键化学关系与路径核对的 ItemUnit。Q016—Q065 是本轮从本地 2024 年高考解析卷整理的 50 个新增 ItemUnit，其中 30 个为选择题，20 个为 6 道完整综合大题中的氧化还原子问；既覆盖单步识别，也覆盖实验保护、流程、配平、滴定终点、定量计算与误差分析。网页保留 45 张必要题图，综合大题的多个子问共用同一张完整题面，避免把上下文切碎。其余本地高考 PDF 仍是候选题源；在题面、图表、答案和路径完成教研复核前，不会显示为“已接入题目”。

## 需要用户判断的问题

1. 学生第一次打开时，更容易理解 A、B、C 中哪一种？
2. “所有连接”与“当前题目只高亮一条路径”是否取得了合适平衡？
3. 节点详情里的边界、例子、探针是否信息过多？
4. 个人证据覆盖层应主要放在全景地图上，还是独立放在诊断矩阵中？

选定方案后，应重新实现正式页面；不要把三个原型方案和切换器直接作为生产代码发布。
